# ❤️ Heart Disease Prediction using Machine Learning

This project predicts whether a patient is at risk of heart disease based on clinical parameters like Age, RestingBP, Cholesterol, MaxHR, and ECG results.

## 📂 Project Files & Structure
- **`predict Heart Disease .ipynb`** — Complete Jupyter Notebook containing data preprocessing, model training, evaluation, and live patient prediction.
- **`heart.csv`** — Dataset containing patient clinical records.

## 🛠️ Technologies Used
- **Python**
- **Pandas & NumPy** (Data Cleaning & Feature Engineering)
- **Scikit-Learn** (Logistic Regression, Random Forest, SVM)

## 📊 Key Steps
1. Data Cleaning & Exploratory Data Analysis (EDA)
2. Encoding Categorical Features (One-Hot & Ordinal Mapping)
3. Model Training & Evaluation (Accuracy & Recall)
4. Live Patient Risk Prediction

## 🚀 How to Run
1. Download `predict Heart Disease .ipynb` and the dataset file (`heart.csv`).
2. Open the notebook in **Jupyter Notebook** or **VS Code**.
3. Run all cells sequentially to train the model and test predictions on new patient data.
